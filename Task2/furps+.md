# FURPS+

| код    | требования                                                                                         |  комментарий
|--------|----------------------------------------------------------------------------------------------------|--------------------------------------
| **F**  | **Функциональные**                                                                                 |
|        | Клиент просматривает на сайте перечень депозитов с актуальными ставками                            |   MVP
|        | Клиент оставляет на сайте заявку на депозит, предавая номер телефона и ФИО                         |      MVP
|        | Передаваемые с сайта данные шифруются                                                              |
|        | Сайт автоматически создаёт обращение в системе call-центра; оператор видит заявку и звонит клиенту | Интеграция сайта - платформа КЦ
|        | Сотрудник бэк-офиса может назначить спец-ставку                                                    | АБС
|        | Обработка заявки фронт-офисом                                                                      | АБС
|        | Получение клиентом СМС при изменении статуса заявки                                                |
|        | Получение клиентом СМС при открытии депозита                                                       |
| **U**  | **Удобство использования**                                                                         |
|        | Единый дизайн и фирменный стиль интерфейсов                                                        |
|        | Интерфейс должен быть интуитивно понятным и простым в использовании                                |
| **R**  | **Надёжность**                                                                                     |
|        | Сервисы должны быть доступны работать 24/7                                                         |
|        | Доступность сервисов 99,9 %                                                                        |
|        | Устойчивость серсиов к сбоям и восстановление после сбоев                                          |
| **P**  | **Производительность**                                                                             |
|        | Отклик по всем операциям не более 300мс                                                            |
|        | Горизонтальное масштабирование сервисов                                                            |
| **S**  | **Поддерживаемость                                                                                 |
|        | Использование технологий с имеющейся экспертизой                                                   | .NET, Java, Oracle, MS SQL
|        | Минимум доработок в ядре интернет-банка подрядчика                                                 |
| **+R** | **+ Ограничения**                                                                                  |                                              
|        | Функциональность отправки СМС нужно разработать внутри банка                                       |                                              
|        | Текущая версия платформы не поддерживает Kafka                                                     |                                              
|        | Избегать прямой работы с БД АБС                                                                    |                                              
|        | АБС масштабируется только вертикально                                                              |
